SynapseTwin is an intelligent, in-browser 3D digital twin platform designed for real-time anomaly detection and predictive maintenance in industrial robotics without relying on cloud inference.

## 🛠️ Key Technical Features
- **In-Browser Machine Learning:** Zero-cloud dependency; executes anomaly detection models client-side with zero latency.
- **Dynamic Shader Mapping:** Custom stress gradient heatmaps pulse directly across kinematic joints upon fault injection.
- **Autonomous Camera Director:** Camera automatically calculates viewing vectors and isolates compromised sub-assemblies during an alert.
- **High-Performance Web3D:** Built on Three.js, maintaining a consistent 60 FPS on standard modern browsers.
